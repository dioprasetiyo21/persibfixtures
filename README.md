# 🐯 PERSIB FIXTURES 2026/2027 ALL COMPETITION

**One Club. One Calendar. Every Match Matters.**

A modern football fixture dashboard dedicated to **Persib Bandung**, bringing match schedules, live updates, results, and statistics together in one place.

🌐 **Website:** https://persibfixtures.vercel.app/

---

## ⚽ About

Persib Fixtures is a TypeScript-powered web application designed for Persib Bandung supporters to follow the team's journey throughout the season.

From upcoming fixtures to completed matches, the application provides an organized and accessible way to keep track of Persib across domestic and international competitions.

## ✨ Features

- 📅 **Match Calendar** — Browse fixtures by season and month.
- 🏆 **Competition Filter** — Explore matches by competition.
- 🔎 **Search** — Quickly find specific matches.
- 🔄 **Schedule & Score Sync** — Refresh fixture schedules and match results.
- 📊 **Match Statistics** — Explore detailed match statistics when available.
- 📝 **Match Details** — View match information, results, and match details.
- 📤 **Export Options** — Export fixtures to CSV and calendar (ICS) formats.
- 🕒 **WIB Timezone** — Match kickoff times displayed in Western Indonesian Time.

## 🛠️ Tech Stack

- Next.js 16
- React 19
- TypeScript
- Tailwind CSS
- shadcn/ui-style components
- SWR and supporting libraries

## 🚀 Getting Started

### Requirements

- Node.js
- pnpm

### Installation

```bash
git clone https://github.com/dioprasetiyo21/persibfixtures.git
cd persibfixtures
npx pnpm@12.3.4 install
```

### Development

```bash
npx pnpm@12.3.4 dev
```

Open [http://localhost:3000](http://localhost:3000) in your browser.

### Production Build

```bash
npx pnpm@12.3.4 build
```
